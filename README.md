# explainer-video has moved to [video-kit](https://github.com/WorthingtonCloud/video-kit)

This skill now lives in **[video-kit](https://github.com/WorthingtonCloud/video-kit)**, together with the sizzle-reel skill, on
one shared engine, with a studio folder that learns your look, voice, music and levels from every video. It's a Claude
Code plugin now. Install it from there:

```text
/plugin marketplace add WorthingtonCloud/video-kit
/plugin install video-kit@video-kit
```

This repo is archived. Its files stay here, read-only, so anything already installed from it keeps working.
